OBS overlay

In OBS, add a Browser Source with this address — the background is transparent, and 450×700 is a good size. For OBS or a browser on another device, use the “on the network” address.

Overlay settings

?size=22font size, px
?font=Namefont: an installed one by name, or a file from the fonts folder (file name without the extension)
?bg=88message background opacity, 0–100 (default 62)
?dir=topchat grows from the top down (default: bottom up)
?platform=0hide the platform icons (Twitch/YouTube)
?badges=0hide the role badges (mod, VIP, sub, member)
?fade=20hide each message after N seconds
?ts=1show each message’s time
?origcolors=1Twitch’s own name colours instead of the pastel palette
?limit=40most messages kept on the page (default 60)
Add settings to the end of the overlay address, joined with &: /overlay?size=20&dir=top&fade=30

Help

  • Your own fonts — drop a .ttf/.otf/.woff2 into the fonts folder next to the program and add ?font=FileName.
  • How the chat looks — all of it lives in public/overlay.css (when building from source); the variables are at the top of the file.
  • Window mode — start the program with --window and this panel opens in its own app window.
  • Settings — config.json next to the program: port, host (127.0.0.1 — this computer only), the list of links. A YouTube channel link like @channel/live can go in before the stream starts — it’s picked up once you’re live.
  • Something wrong? — look in error.log next to the program; issues go to github.com/IamMrCupp/duplexchat.
